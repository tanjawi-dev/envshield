# Security Policy

The EnvShield team takes security vulnerabilities very seriously.

---

## Supported Versions

Only the latest release receives active security patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within EnvShield:

1. **Do not create a public issue on GitHub.**
2. Please report security issues confidentially via [GitHub Private Vulnerability Reporting](https://github.com/tanjawi-dev/envshield/security/advisories/new) or by contacting `tanjawi-dev@users.noreply.github.com`.
3. Include a description of the vulnerability, steps to reproduce, and potential impact.

You will receive an acknowledgment within 48 hours, followed by updates on the fix and release schedule.
